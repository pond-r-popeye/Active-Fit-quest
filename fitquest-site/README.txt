Fit Quest - วิธีเพิ่มท่า/เซ็ต (แก้ที่ catalog.json เท่านั้น)

โครงสร้างใน GitHub (อยู่ระดับเดียวกัน):
  index.html
  catalog.json   <- รายการท่า (ex) และเซ็ต (sets)
  media/         <- รูป/GIF ประกอบท่า

ขั้นตอนเพิ่มท่าใหม่
1) อัปโหลดรูปเข้าโฟลเดอร์ media (ตั้งชื่ออะไรก็ได้ เช่น lat-pulldown.jpg ห้ามมีช่องว่าง)
2) เปิด catalog.json ใน GitHub กดแก้ (ไอคอนดินสอ)
3) ในลิสต์ "ex" เพิ่มก้อนท่าใหม่ต่อท้าย (อย่าลืมเครื่องหมาย , คั่นระหว่างก้อน):
   {"id":"e_latpull","name":"Lat Pulldown","type":"w","eq":"Cable","mu":["back","biceps"],
    "media":"media/lat-pulldown.jpg","m":"wr","ps":3,"pr":12,"pk":0,"mx":50,"my":50}
4) ถ้าต้องการใส่ในเซ็ต ให้เพิ่ม id ของท่านั้นในลิสต์ "ex" ของเซ็ตที่ต้องการ
5) กด Commit changes แล้วรอ Cloudflare อัปเดต 1-2 นาที จากนั้นรีเฟรชหน้าเว็บ

ความหมายของช่อง (ท่า)
  id    ชื่อรหัสไม่ซ้ำกับท่าอื่น ใช้ตัวอักษรอังกฤษ/ตัวเลข/_
  name  ชื่อท่า
  type  w = เวทเทรนนิง, c = คาร์ดิโอ, y = โยคะ
  eq    อุปกรณ์ คั่นด้วย , หรือเว้นว่าง ""
  mu    กล้ามเนื้อ เลือกจาก: chest shoulder biceps triceps forearm abs back glutes quads hams calves (ว่างได้ [])
  media พาธรูป เช่น "media/ชื่อไฟล์.jpg" หรือ "" ถ้าไม่มีรูป
  m     โหมดบันทึก: wr = น้ำหนัก+จำนวนครั้ง, r = จำนวนครั้งอย่างเดียว, t = เวลา
  ps    จำนวนเซ็ตเริ่มต้น     pr  จำนวนครั้งเริ่มต้น     pk  น้ำหนักเริ่มต้น (กก.)
  pt    เวลาเริ่มต้น (วินาที) ใช้กับโหมด t / คาร์ดิโอ / โยคะ
  mx,my ตำแหน่งโฟกัสรูป (0-100) ใช้ 50,50 ได้เลย

เพิ่มเซ็ตใหม่ ในลิสต์ "sets":
   {"id":"s_back2","name":"Back Day 2","type":"w","ex":["e2","e_latpull"],"rd":1}
  ex = รายชื่อ id ของท่าตามลำดับ, rd = จำนวนรอบ

ข้อควรระวัง
- JSON เข้มงวด: ใช้ " " ตรง ๆ, ห้ามมี , เกินท้ายสุดของลิสต์
- ตรวจความถูกต้องก่อน commit ได้ที่ jsonlint.com
- ถ้าแก้ผิดแล้วหน้าเว็บไม่เปลี่ยน แอปจะใช้ท่าชุดเดิมที่ฝังไว้ ไม่พัง
- อย่าแก้ท่า/เซ็ตในหน้าแอปบน pages.dev เพราะจะถูกไฟล์นี้ทับทุกครั้งที่เปิด
- บันทึกการออกกำลังกาย น้ำหนัก ปฏิทิน ยังเก็บในเบราว์เซอร์แต่ละเครื่อง (ยังไม่ซิงก์)
